# Movie Review System

A console-based movie review application built with Java and MySQL.

## Features
- Add and remove movies
- Add reviews for movies
- Search movies by title
- Display all reviews for a movie
- Get average rating for a movie
- Update movie details

## Technologies
- Java
- MySQL
- JDBC (PreparedStatement)

## Concepts Used
- OOP (Classes, Encapsulation, Getters)
- Exception Handling (Custom Exception: MovieNotFound)
- Collections
- Database: CRUD operations, Foreign Key, CASCADE DELETE

## Setup
1. Create database: `movie_review_system`
2. Create tables: `movie` and `review`
3. Add MySQL connector JAR to project
4. Update `url`, `username`, `password` in `Main.java`
5. Run `Main.java`
